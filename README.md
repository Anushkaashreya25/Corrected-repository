# Corrected-repository — Academic Help

This repository will host the Academic Help website: a platform where students can post requests for assistance and helpers can donate money or pledge support.

This initial commit creates the repository README so we can add a feature branch with the website scaffold.

Planned stack (prototype): Next.js + Tailwind CSS, NextAuth for auth, Prisma + SQLite (prototype) / PostgreSQL (prod), Stripe (test mode) for donations.
